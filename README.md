### Instrucciones de Instalación y Ejecución

#### Requisitos previos
Para levantar este proyecto de manera local, lo primero a considerar es tener instalado:
- **Python:** versión 3.10 o superior.
- **Manim Community:** versión v0.19.0 o superior.

#### Pasos de instalación
**1. Clonar repositorio:**
```bash
git clone [https://github.com/SofiNazaMorales/EID-MATE1134-1-2026-2](https://github.com/SofiNazaMorales/EID-MATE1134-1-2026-2)
```

**2. Crear y activar el entorno virtual (Obligatorio para aislar dependencias):**

*Para Linux o macOS:*
```bash
python3 -m venv venv
source venv/bin/activate
```

*Para Windows*
```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**3. Instalar las dependencias del proyecto:**
```bash
pip install -r requirements.txt
```
